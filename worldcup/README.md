## 📋 功能说明

### 🔮 预测（默认首页）
每场比赛展示：
- **推荐方向**：主胜/客胜/平局 + 信心星级
- **预测比分**：波胆估算
- **赔率对比**：欧洲最优赔率 vs 竞彩换算赔率
- **三档策略**：
  | 档位 | 说明 |
  |------|------|
  | 🛡️ 保守 | 稳字当头，赔率≤2.50，单关为主 |
  | ⚡ 均衡 | 收益风险兼顾，赔率≤5.00 |
  | 🔥 激进 | 追求高回报，波胆/串关，无上限 |

### 📊 分析
- **单场查看**：下拉选择比赛，展开完整分析报告
- **今日全部**：当天所有比赛汇总，点击展开详情

### 💰 购彩建议
- 切换保守/均衡/激进策略
- 勾选比赛加入串关方案
- 自动计算串关赔率和回报
- 生成投注单预览
